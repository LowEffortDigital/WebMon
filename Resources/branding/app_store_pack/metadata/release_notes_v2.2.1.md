# WebMon v2.2.1 for macOS & iOS/iPadOS (Build 35)

## What's New in v2.2.1 (Build 35)
- **12 Adaptive Telemetry Card Styles & Full macOS ↔ iOS/iPadOS Parity**: Switch any web or API widget between Live WebKit DOM view and 12 native SwiftUI Telemetry Card styles (`History Bars`, `Area Line`, `Horizontal Bar`, `Tachometer`, `Utilization Ring`, `Stat Tiles`, `Half Gauge`, `Signal Strip`, `Delta Comparison`, `Hero Center Metric`, `Key-Value Table`, and `Monospace Terminal`).
- **Smart Data Dissolve Engine & HTML Artifact Stripping**: Automatically strips raw HTML tag noise, dissolves `Label : Value` pairs, parses duration-aware numeric metrics and units, and auto-heals multi-component structured selectors.
- **Static Text, Environment Variables, Date/Time Presets & Per-Item Typography**: Compose custom widget items with Static Text, Environment Variables (`$USER`, `$HOST`, `$SHELL`, `$PWD`), and Live Date/Time Presets with per-item Font Size, Weight, Style, Design, and Color formatting.
- **Header & Cross-Icon Drag Anchors + Active-Screen Multi-Display Placement**: Reposition floating desktop widgets effortlessly using the header bar or dedicated cross-arrow move anchor, with active-display placement across multi-monitor setups.
- **Live Telemetry Card Refresh & SPA Route Support**: Reliable Soft DOM Poll, In-Page Fetch Re-Run, and Full Page Reload across SPA routes with 10–15s DOM settle protection.
- **iOS 16.0+ & Native iPad / ExtraLarge Widget Support**: Universal iPhone + iPad layouts, ExtraLarge iPad Home Screen widgets, and Sign in with Apple cross-device iCloud sync (`iCloud.com.loweffort.webmon`).
