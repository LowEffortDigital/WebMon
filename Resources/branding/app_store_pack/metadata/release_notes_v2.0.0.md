# WebMon v2.0.0 Release Notes (Build 20)

**WebMon v2.0.0** (formerly *WebWidget*) unifies the Low Effort Digital desktop monitoring suite (`PerfMon`, `EventMon`, `VolMon`, `WebMon`) across macOS 14+ and Windows 11.

## Highlights in v2.0.0
- **Standardized Suite Naming & `WM` Monogram**: Renamed from *WebWidget* (`WW`) to **WebMon** (`WM`) with seamless automatic migration of existing `com.loweffort.webwidget` preferences and saved desktop widgets.
- **Interactive WebKit / WebView2 DOM Component Picker**: Hover and click any website component (`<div>`, `<section>`, `<table>`, metric cards, charts) to isolate and pin it as a resizable floating desktop widget.
- **Toggleable Header/Footer Chrome & 100% Full-Card Bleed**: Show or hide Header and Footer bars independently, or hide both so your selected web component fills 100% of the HUD card edge-to-edge with a hover-only control pill.
- **Intermittent Auto-Refresh Engine & Local Credential Vault**: Schedule independent per-widget refresh intervals (`5s` to `60m`) with hardware-backed local credential auto-fill, HTTP Basic Auth, Bearer tokens, and persistent session cookies.
- **Low Effort Suite v2.0 Theme & Icon Sync**: Synchronize 9 studio color themes, custom hex accents, and persistent Dock/Taskbar icons across `PerfMon`, `EventMon`, `VolMon`, and `WebMon`.
